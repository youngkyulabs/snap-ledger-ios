개인정보 처리방침

앱: 찰칵가계부 (SnapLedger) · 발효일: 2026년 5월 24일

찰칵가계부(이하 "앱")는 사용자의 개인정보를 수집·저장·전송하지 않습니다. 본 처리방침은 앱이 어떻게 데이터를 다루는지 투명하게 설명합니다.

1. 수집하는 정보

없습니다. 앱은 다음 어떤 정보도 수집하지 않습니다.

  • 이름, 이메일, 전화번호 등 식별 정보
  • 위치 정보
  • 기기 식별자, 광고 식별자
  • 사용 분석, 충돌 보고서
  • 결제 정보, 카드 번호, 거래 내역

2. 사용자 데이터의 처리 방식

  • 온디바이스 처리: 영수증·결제 알림 이미지의 문자 인식(OCR)과 항목 추출(Apple Intelligence)은 모두 사용자의 기기 안에서만 실행됩니다. 어떤 데이터도 외부 서버로 전송되지 않습니다.
  • 사용자 지정 폴더 저장: 추출된 가계부 항목은 사용자가 직접 선택한 iCloud Drive 폴더의 CSV 파일(expenses-YYYY-MM.csv)로만 저장됩니다. 앱 자체 서버나 클라우드 계정에는 보관되지 않습니다.
  • iCloud Drive: CSV 파일이 iCloud Drive에 위치할 경우, 해당 데이터의 동기화·저장은 Apple의 iCloud 정책을 따릅니다. 앱은 iCloud 계정에 접근하거나 데이터를 읽지 않습니다.
  • 공유 시트로 수신한 이미지: 공유 시트에서 받은 이미지는 앱 그룹 컨테이너의 임시 폴더(inbox)에 저장되며, 처리 후 자동 삭제됩니다.

3. 권한 사용

  • 알림(선택): 사용자가 허용한 경우, 매일 저녁 검토 알림을 표시합니다. 알림 내용은 기기에서 직접 생성되며 외부로 전송되지 않습니다.
  • 백그라운드 새로 고침(선택): 검토 대기 항목을 백그라운드에서 처리합니다. 네트워크 통신 없이 기기 내부에서만 동작합니다.
  • 파일 접근: 사용자가 폴더 선택기를 통해 명시적으로 허용한 폴더에 한해 CSV 파일을 읽고 씁니다.

4. 제3자 공유

앱은 어떤 제3자 분석 도구, 광고 SDK, 외부 서비스도 사용하지 않습니다. 따라서 제3자에게 공유할 데이터 자체가 존재하지 않습니다.

5. 어린이 정보

앱은 어린이를 포함한 어떤 사용자로부터도 개인정보를 수집하지 않습니다.

6. 사용자의 권리

모든 데이터는 사용자가 지정한 폴더의 파일에만 존재하므로, 사용자가 직접 파일을 열람·복사·삭제할 수 있습니다. 앱을 삭제하면 앱 그룹 컨테이너의 모든 데이터(검토 대기 항목, 학습된 가맹점-카테고리 매핑 등)가 함께 제거됩니다. 사용자가 지정한 폴더의 CSV 파일은 사용자가 직접 삭제해야 합니다.

7. 보안

앱은 네트워크 통신을 수행하지 않으므로 전송 중 데이터 노출 위험이 없습니다. 기기 내 저장 데이터는 iOS의 표준 샌드박스 보호를 받습니다.

8. 변경 사항

본 처리방침은 기능 변경에 따라 갱신될 수 있습니다. 중요한 변경이 있을 경우 앱 업데이트 노트에 안내됩니다. 최신 버전은 항상 본 페이지에서 확인할 수 있습니다.
