카드 결제 알림 스크린샷이나 영수증을 공유 시트로 보내기만 하면, Apple Intelligence가 금액·가맹점·카테고리를 자동으로 채워 가계부에 정리합니다. 모든 인식과 추출은 기기 안에서 이루어지며, 결제 정보가 Apple 외부 서버로 전송되지 않습니다.

주요 기능

  • 공유 시트로 결제 알림·영수증 한 번에 캡쳐
  • 한 이미지에서 여러 건의 결제도 자동 분리
  • 가맹점 → 카테고리 자동 학습
  • 카테고리별 월 예산 한도와 사용률 진행률
  • 수입·카드·저축·계좌 잔액으로 한 달을 맞춰보는 월 정산
  • iCloud로 기기 간 자동 동기화 + 선택적 월별 CSV 백업
  • 온디바이스 인식·추출 — 광고·분석 SDK 없음, 개발자 서버 없음
