# 스크린샷용 샘플 데이터

App Store 스크린샷·데모용으로 미리 채워둘 수 있는 샘플 데이터.
실제 앱이 쓰는 CSV 포맷(UTF-8 BOM + 헤더)과 동일하므로 iCloud Drive 연동 폴더에
그대로 넣으면 가져오기로 반영된다.

**스크린샷의 기준 달(hero month)은 5월(2026-05)** 이다. 마감된 과거 달이라
정산이 "정상 · 차이 없음"으로 확정 표시되고, 한 달 전체 지출이 차 있어
통계 도넛·예산 사용률이 가장 보기 좋다. 통계·예산·정산 탭은 현재 달(6월)이
기본이므로 **좌우로 스와이프해 5월로 이동한 뒤 캡처**한다.

## 파일

| 파일 | 포맷 | 설명 |
|---|---|---|
| `expenses-2026-05.csv` | `날짜,설명,카테고리,금액,메모` | 5월 한 달 전체 지출 (37건, 합계 876,500원) |
| `expenses-2026-06.csv` | 〃 | 6월 중순까지 부분 지출 (현재 월, 19건) |
| `reconciliations-2026-05.csv` | `종류,항목,계좌,방향,금액,메모` | 5월 정산 — 합산 시 "정상 차이 없음"으로 떨어지도록 맞춤 |
| `reconciliations-2026-06.csv` | 〃 | 6월 진행 중 정산 (기초잔액 = 5월 기말, 연속성 유지) |
| `review-input-samples.md` | 텍스트 | 검토 화면을 채울 카드 알림/영수증 샘플 텍스트 |

## 카테고리

기본 10종만 사용: 식비 · 카페 · 생활 · 교통 · 쇼핑 · 공과금 · 구독 · 의료 · 문화 · 기타
(`AppSettings.swift`의 기본값과 일치 → off-list 경고 없이 깔끔하게 보임)

## 예산 한도 (앱에서 직접 입력)

카테고리별 월 한도(`CategoryBudget`)는 CSV가 아니라 **SwiftData에만 저장**되므로
가져오기로는 채워지지 않는다. 예산 탭 스크린샷을 위해 앱에서 아래 값을 직접 입력한다.
5월 실지출과 맞물려 **초과 1건(교통)·주의 1건(식비)·여유 다수**의 읽기 좋은 분포가 나온다.

| 카테고리 | 5월 지출 | 추천 한도 | 사용률 | 상태 |
|---|--:|--:|--:|---|
| 교통 | 109,100 | 100,000 | 109% | 🔴 초과 — 경고 표시 데모 |
| 구독 | 28,400 | 30,000 | 95% | 고정비, 거의 참 |
| 공과금 | 93,600 | 100,000 | 94% | 고정비, 거의 참 |
| 식비 | 180,200 | 200,000 | 90% | 🟡 주의 |
| 문화 | 60,300 | 70,000 | 86% | 🟢 여유 |
| 쇼핑 | 196,500 | 250,000 | 79% | 🟢 여유 |
| 카페 | 43,300 | 60,000 | 72% | 🟢 여유 |
| 생활 | 141,700 | 200,000 | 71% | 🟢 여유 |
| 의료 | 23,400 | 50,000 | 47% | 🟢 여유 |
| 기타 | 0 | (미설정) | — | — |

> 교통이 한도를 넘겨 예산 탭 상단에 빨간 경고로 뜨는 게 핵심 컷.
> 정산 CSV의 월메모도 "교통비가 예산을 넘김"으로 맞춰 두 화면의 스토리를 일치시켰다.

## 화면별 체크

- **검토**: `review-input-samples.md`의 4번(여러 건 묶음)이 한 장에서 4행이 한꺼번에
  채워지는 가장 강한 컷. 가맹점·금액·카테고리·날짜가 또렷하게 들어온다.
- **최근 기록**: 5월 리스트 상단(05-31·05-30)이 식비·카페·쇼핑·문화로 다양하게
  섞이도록 구성. 월별 그룹 헤더가 보이게 스크롤 위치를 맞춘다.
- **통계**: 쇼핑·식비·생활이 큰 슬라이스, 나머지가 작은 슬라이스라 도넛이 균형 있게
  보인다. 전월 대비 비교까지 함께 잡으면 좋다.
- **예산**: 위 한도표대로 입력. 교통 초과(빨강) + 식비 주의(노랑) + 여유 다수.
- **정산**: 5월로 이동하면 "정상 · 차이 없음"(초록). 실제 쓴 돈 = 기록한 돈 = 876,500원.

## 사용법

1. 설정에서 연동한 iCloud Drive 폴더에 `expenses-*.csv` / `reconciliations-*.csv`를 복사.
2. 앱 재진입 → 동기화가 파일을 읽어 최근 기록·통계·예산 탭에 반영.
3. 예산 탭에서 위 한도표대로 카테고리 한도를 입력.
4. 검토 탭 스크린샷은 `review-input-samples.md`의 블록을 알림/메모 앱에 붙여 캡처 후 공유.

> 정산 CSV의 `종류` 값은 `수입 / 카드사용액 / 저축액 / 기초잔액 / 기말잔액 / 이자 / 자금변동 / 월메모` 중 하나여야 한다.
> `기초·기말잔액·이자`는 `계좌`, `자금변동`은 `방향(입금/출금)`이 필수.
