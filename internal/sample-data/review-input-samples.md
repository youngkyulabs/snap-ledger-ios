# 검토 화면용 샘플 입력 텍스트

스크린샷용 검토(추출) 화면을 채우기 위한 샘플 입력 모음.
실제로는 **카드 결제 알림 스크린샷**이나 **영수증 사진**을 공유받아 OCR → 추출하지만,
이미지를 따로 만들기 어려우면 아래 텍스트를 그대로 알림/메모 앱에 붙여 캡처해 공유하거나,
추출 로직을 테스트할 입력으로 사용할 수 있다.

각 블록은 한 건의 공유(=한 장의 스크린샷)에 해당한다.

---

## 1. 카드 결제 알림 — 단건 (가장 흔한 형태)

```
[신한카드] 승인 김O규님
5,800원 일시불
05/14 13:22
스타벅스 강남점
누적 1,240,500원
```

## 2. 카드 결제 알림 — 단건 (체크카드)

68,400원
이마트 성수점
06/02 19:41
잔액 1,301,600원
```

배달의민족

```

---

## 메모

- 1·2번처럼 **연도 없이 `MM/DD`만** 있는 알림이 대부분 → 추출 후 오늘 연도로 보정됨
  (`ExtractionService.normalizeYear` 참고).
- 4번은 한 장에서 **여러 거래**가 나오는 케이스라 검토 목록에 4행이 한꺼번에 채워진다.
- 5·6번 영수증은 품목 합계만 한 건으로 추출되며, 카테고리는 가맹점 기준으로 추론된다
  (예: 홈플러스→생활, 투썸→카페).
- 가맹점명은 추출 시 정규화될 수 있다(예: `NETFLIX.COM`→넷플릭스, `KAKAO PAY`→카카오페이).
